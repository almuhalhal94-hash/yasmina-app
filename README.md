# ياسمينة 🌸 — نسخة مدرسة المستقبل الابتدائية للبنات

تطبيق ويب تعليمي (PWA) لطالبات الصف الأول: حفظ القرآن الكريم، «كتب مدرستي» (تلاوتي، ديني، وطني البحرين، English ABC، مرسم الحروف)، وإنجليزي بالألعاب والأصوات.

- يتثبّت كتطبيق على آيفون/آيباد/أندرويد/كمبيوتر بدون متجر، ويشتغل بدون نت بعد أول فتح.
- كل بيانات الطالبة على جهازها فقط (لا حسابات ولا خوادم).
- بلا موسيقى ولا وجوه.

## التشغيل
موقع ثابت: افتح `index.html` عبر أي خادم (GitHub Pages مثلًا).

## النشر على GitHub Pages
1. Settings ← General ← Change visibility ← **Public** (Pages المجانية تحتاج مستودع عام).
2. Settings ← Pages ← Source: **Deploy from a branch** ← اختر الفرع اللي فيه الملفات (`claude/modest-volta-52gl9z` أو `main` بعد الدمج) ← `/ (root)` ← Save.
3. الرابط: `https://almuhalhal94-hash.github.io/yasmina-app/`

## حقيبة المدرسة (`school-kit/`)
- `مقترح-ياسمينة-مدرسة-المستقبل.pptx` — عرض المقترح للإدارة (12 شريحة).
- `فيديو-تثبيت-ياسمينة.mp4` — نفس الفيديو بدون صوت (نقرات خفيفة فقط).
- `إعلان-ياسمينة-واتساب.png` و`إعلان-ياسمينة-A4-للطباعة.pdf` — إعلان فيه رمز QR.
- `رمز-QR-ياسمينة.png` — رمز يفتح رابط التطبيق.
